# bill-checker

A phone app that reads a Western Cape municipal bill from a photo or a PDF, checks every line against the
municipality's own tariffs, and drafts the dispute for the resident to send. It checks the bills of three
municipalities first: Cape Town, Swartland and Overstrand. It is built on the
[louis-agent](https://github.com/bosbevk/louis-agent) framework's packages.

Nothing of the app is built here yet. The plan is in the framework's repository,
[F171 The bill checker](https://github.com/bosbevk/louis-agent/blob/main/src/docs/plans/F171-the-bill-checker.md),
in eight parts. The first part lives in the framework itself: a photo or a PDF reaching
a tool, [F171.1](https://github.com/bosbevk/louis-agent/blob/main/src/docs/plans/F171.1-a-photo-or-a-pdf-reaches-a-tool.md),
which has started. The app's own code comes here after it.

## The brand

What the app looks and sounds like is in [docs/brand](docs/brand/README.md): the mark, the colours, the type and
the voice, with the marks as SVG and the store and social images. Klopdit is a working name until the name is
picked.
